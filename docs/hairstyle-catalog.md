# 헤어스타일 추천 카탈로그 입력 안내

`hairstyle-catalog-template.csv`는 운영 데이터 검수용 템플릿이다. 복수 값은 `|`로 구분하고 enum 이름은 서버 값과 동일하게 입력한다.

- 필수: `style_name`, `category`, `service_types`, 호환 모발 정보, 관리 시간, 난이도, 스트레스 수준, 우선순위, 메타데이터 버전
- 이미지는 저작권이 확인된 파일만 S3에 업로드하고 DB에는 `file_id`만 연결한다.
- 운영 seed에는 외부 공개 URL이나 검수되지 않은 예시 스타일을 넣지 않는다.
- 실제 스타일·호환성 데이터는 디자이너 또는 도메인 담당자의 검수를 거쳐야 한다.

## 추천 길이 및 갱신 기준

- 현재 머리 길이가 있으면 `minimum_hair_length`와 `compatible_hair_lengths`의 최단 길이 중
  더 긴 길이를 최소 필요 길이로 사용한다. 최소 길이가 누락돼도 호환 길이로 검증한다.
- 두 길이 정보가 모두 없으면 길이를 확인할 수 없으므로 해당 후보를 제외한다.
  사용자의 길이 입력 자체가 없는 경우에는 기존 콜드 스타트 동작을 유지한다.
- 긴 머리 사용자가 짧은 커트를 선택하는 것은 허용한다. 시술 이력·선호 점수가 높아도
  현재 머리보다 긴 길이가 필요한 후보는 통과하지 않는다.
- `/recommendations/latest`는 기존 실행이 있을 때 현재 입력과 알고리즘을 검증하고,
  변경됐거나 STALE인 결과는 재생성한다. 변경이 없으면 기존 실행을 재사용한다.
  최초 실행이 없으면 404, 적합한 후보가 없으면 422를 반환한다.
- 카탈로그 호환성·점수·정렬 조건도 입력 해시에 포함한다. 운영 메타데이터 버전을 빠뜨린
  수정도 이전 결과를 재사용하지 않는다. `/recommendations/{id}`는 과거 실행 조회를 유지한다.
- `force_refresh=true`는 새 실행을 만들지만 같은 입력의 순위를 무작위로 섞지는 않는다.
