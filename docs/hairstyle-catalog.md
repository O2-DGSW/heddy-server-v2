# 헤어스타일 추천 카탈로그 입력 안내

`hairstyle-catalog-template.csv`는 운영 데이터 검수용 템플릿이다. 복수 값은 `|`로 구분하고 enum 이름은 서버 값과 동일하게 입력한다.

- 필수: `style_name`, `category`, `service_types`, 호환 모발 정보, 관리 시간, 난이도, 스트레스 수준, 우선순위, 메타데이터 버전
- 이미지는 저작권이 확인된 파일만 S3에 업로드하고 DB에는 `file_id`만 연결한다.
- 운영 seed에는 외부 공개 URL이나 검수되지 않은 예시 스타일을 넣지 않는다.
- 실제 스타일·호환성 데이터는 디자이너 또는 도메인 담당자의 검수를 거쳐야 한다.
